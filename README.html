ITSI Workshop for O11y SAs

Purpose: This workshop helps Solutions Architects with AppDynamics and Splunk Observability Cloud (O11y) experience learn how to bring AppDynamics, Splunk Observability Cloud, and ThousandEyes data into Splunk ITSI, then build services and episodes.

Overview

This workshop is designed to provide the core knowledge required to build a quick ITSI Proof of Concept (POC) using three observability data sources:

  • AppDynamics
  • Splunk Observability Cloud
  • ThousandEyes

No deep Splunk expertise is required.

Workshop Goals

By the end of this workshop, you will:

  • Understand the key ITSI components involved in multi-source integrations
  • Know how to install required add-ons and configure the relevant content packs
  • Have a working environment to continue exploring and expanding your ITSI knowledge

What This Workshop Covers

  1. Bringing data from AppDynamics, Splunk Observability Cloud, and ThousandEyes into ITSI
  2. Creating Services and KPIs in ITSI using these three data sources
  3. Creating Notable Events and Episodes from these three data sources

What This Workshop Does Not Cover

  • In-depth ITSI training
  • Advanced topics such as thresholding, entity discovery, anomaly detection, prediction, and similar concepts

Prerequisites

  • Splunk Observability Cloud: Access to Splunk Observability Workshop AMER organization or another organization where you can generate an API token
  • AppDynamics: Access to the se-lab or another tenant where you can create an API token >If you are a splunk SA with @cisco user you should have access
  • ThousandEyes:
  • Access to ThousandEyes (if you do not have access, sign up for a trial account)
  • Create a test and an alert as described here

Workshop Modules

  1. AppDynamics Data Integration
  2. ThousandEyes Data Integration
  3. Splunk Observability Cloud Data Integration
  4. Content Pack Installation and Configuration
  5. Service and KPI Configuration
  6. Notable Events and Episodes

Recommended STEP Courses
