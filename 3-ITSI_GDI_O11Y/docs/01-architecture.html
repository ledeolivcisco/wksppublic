1. Architecture

Overview

The Splunk Infrastructure Monitoring (SIM) Add-on is the core component that enables Observability Cloud (O11y) metrics to be consumed in Splunk ITSI.

Operating Modes

The add-on supports two distinct modes of operation:

🔴 sim Command — Live Query (Recommended for ITSI KPIs)

Executes SignalFlow programs on O11y in real time.

Property Details
Speed ⚡ Lightning-fast
Best for ITSI KPI base searches
Index usage ❌ No index duplication
License impact None

🔵 Modular Inputs — Indexed Mode

Polls O11y periodically and stores metric summaries in the sim_metrics index.

Property Details
Speed Periodic polling
Best for Historical analysis, dashboard data
Index sim_metrics
License impact ✅ Excluded from license charges when using stash sourcetype

Key Recommendation
