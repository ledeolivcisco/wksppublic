Installing the Splunk App for Content Packs

← Back to README

This page walks you through installing the Splunk App for Content Packs on your Splunk environment. The app is the prerequisite for all content pack installations described in this guide.

📚 Official documentation: Install the Splunk App for Content Packs

⚠️ Important Notes Before You Begin

  • Splunk Cloud Platform customers cannot self-install the app. You must file a support case via the Splunk Support Portal or contact Splunk Customer Support to request installation.
  • ITSI / ITE Work 4.8.x and lower do not support installation via the Splunk App for Content Packs. In those cases, download the content pack as a backup ZIP file and restore it using the backup/restore functionality.
  • The app cannot be installed from the Splunk Web interface. You must use the command line.

Single-Instance (On-Premises) Installation

  1. Download the Splunk App for Content Packs from Splunkbase.

  2. Place the downloaded .spl file in $SPLUNK_HOME/etc/apps: bash cp splunk-app-for-content-packs_<version>.spl $SPLUNK_HOME/etc/apps/

  3. Stop your Splunk deployment: bash $SPLUNK_HOME/bin/splunk stop

  4. Extract the installation package: bash cd $SPLUNK_HOME/etc/apps tar -xzf splunk-app-for-content-packs_<version>.spl

    Windows users: Rename the file extension from .spl to .tgz first and use a third-party utility to extract it.

  5. The extracted directories will follow the naming convention:

  6. DA-ITSI-CP-<contentpack>

  7. DA-ITSI-ContentLibrary

  8. Start your Splunk deployment: bash $SPLUNK_HOME/bin/splunk start

Search Head Cluster (Distributed) Installation

  1. Download the Splunk App for Content Packs from Splunkbase.

  2. On the deployer, extract the package into the SHC apps directory: bash cd $SPLUNK_HOME/etc/shcluster/apps tar -xzf splunk-app-for-content-packs_<version>.spl

  3. Push the app to all cluster members. The -target parameter should point to the URI and management port of any single cluster member (the deployer pushes to all members automatically): bash $SPLUNK_HOME/bin/splunk apply shcluster-bundle \ -target https://<search-head-member>:8089 \ -auth admin:<password>

Post-Installation: First-Time Setup

After installation, perform the following from within ITSI or ITE Work:

  1. From the ITSI main navigation bar, click Search.
  2. Run the search provided in the post-installation instructions to create any required lookup files.
  3. Navigate to Configuration > Data Integrations.
  4. Click the Content Library tab to see the list of available content packs.
