Overview

The Splunk App for Content Packs provides prepackaged content that accelerates the setup of your Splunk IT Service Intelligence (ITSI) or IT Essentials Work (ITE Work) environment. This content includes pre-configured KPI base searches, service templates, saved glass tables, entity discovery searches, and other objects ready for use inside ITSI.

⚠️ Important: Treat this pack as an implementation accelerator, not a plug-and-play solution. We strongly recommend not simply installing and enabling everything at once — doing so can introduce serious performance issues or other undesirable behaviors in your environment. Follow the step-by-step instructions in this guide to selectively enable only the components relevant to your data sources.

Once installed, the Splunk App for Content Packs becomes available under Configuration > Data Integrations in the ITSI main menu. Navigate to the Content Library tab to browse and install individual content packs.
